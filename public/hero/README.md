# Hero Section Assets

This directory should contain the following image files for the hero section:

## Required Images:

1. **art.svg** - Icon/image for the "Plugin Playground" card
2. **frame-3.svg** - Logo/header icon
3. **frame.svg** - Image for the "Seamless Variables" card
4. **group-1940.png** - Image for the "Interactive Components" card
5. **group-1437255950.png** - Decorative background image
6. **illustration.png** - Image for the "Accessible Prototypes" card
7. **image.png** - Image for the "Accessible Prototypes" card (second instance)
8. **image.svg** - Icon for the "Solutions" navigation item
9. **vector-2.svg** - Icon for the "Community" navigation item
10. **vector-3.svg** - Icon for the "Resources" navigation item
11. **vector.svg** - Icon for the "Products" navigation item

## Instructions:

1. Export all images from your Figma design
2. Place them in this directory (`public/hero/`)
3. Ensure the filenames match exactly as listed above
4. The component will automatically reference these images

## Image Sizes (Recommended):

- SVG files: Optimized for web
- PNG files: Use appropriate sizes (the component will scale them)
  - Cards: ~200-300px width
  - Background: ~1200px width
